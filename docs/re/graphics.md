# Graphics text

All screen graphics are uncompressed 4bpp tiles + u16 maps (tools/gfx.py has the format). English redraws are
generated by `tools/gfxtext.py` from `script/graphics.json`, `script/tutorial.json` and `script/screens.json`
(kinds: caption, page, pool, logo) and written into the expanded ROM area (0x400000+) by build.py, which repoints
the descriptor's tile pointer and map slot(s). Never edit tiles in place.

## Resource format
- Descriptor (12 bytes): `{u32 tiles -> {u32 size, tiles}, u32 map slot -> {u16 w, u16 h, entries}, u32 palettes
  -> {u16 count, colours}}`. Map entries are relative to the image's own tiles and palettes.
- Pools: one descriptor whose map slot is the first of N consecutive slots; each slot is a small piece that code
  draws at a fixed screen position (options, records, pause, results, time attack). `tools/pool.py`.
- Map slots live at 0x3D84xx-0x3DAxxx; scene image lists at 0x3D75E8 (intro captions) and 0x3D762C (ending).
- Credits: descriptor 0x337E6C, one 30x140 map scrolled by the rectangle copier 0x08002374.

## Tile budgets (VRAM)
caption: BG1 char 2, base 0, <= 512 | page: BG0 char 0, <= 1024 | logo: BG2 char 2, BG1 tiles from 0x100, <= 256 |
pool: <= original count (options pool spans char blocks 1-2) | credits: <= 1002 (original).

warp.lua (stage index), scene.lua (13 = ending), gallery.lua (every dialogue slot), gfxlog.lua, maprect.lua,
winlog.lua, glyphlog.lua, romreads.lua. Mesen keeps .sav files between runs: always pass --sav
(work/saves/blank.sav or village.sav).
